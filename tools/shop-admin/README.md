# 상점 관리 프로그램

시트 이미지를 올리면 자동으로 잘라서 상점(`www/js/shopdata.js` + `www/images/`)에 올려 주는 프로그램이에요.
내 컴퓨터(localhost)에서만 열려요.

## 켜기
```
npm install        # 처음 한 번만
npm run admin      # 브라우저가 자동으로 열려요 (http://localhost:5050)
```
끄려면 터미널에서 `Ctrl+C`.

## 쓰는 법
1. **시트 이미지 고르기** — 정사각형 칸에 검은 격자선이 또렷한 이미지 (4x4, 2x2, 3x3, 4x3 등). 칸 수는 자동으로 찾고, 틀리면 "칸 수"에서 직접 고르세요. 칸 번호는 왼쪽 위부터 가로로 1, 2, 3… 이에요.
2. **타일 테마 시트**
   - *새 테마로 추가*: id(영문), 이름, 분류, 설명, 타일 이름을 적고 올려요. 14칸(2~8192 + 큰 이미지)이 필요해요.
   - *기존 테마 덮어쓰기*: 덮어쓸 테마를 고르면 지금 그림과 새 그림이 나란히 보여요. 바꿀 타일만 체크하세요. "새 시트 칸"으로 어느 칸의 그림을 쓸지도 고를 수 있어요.
3. **프로필 사진 시트** — 올릴 칸만 체크하고 id(영문)·이름·가격(0이면 무료)을 적어요. 이미 있는 id 를 쓰면 그 사진의 그림이 바뀌어요.
4. **물건 관리** (시트 없이 쓰는 탭) — 프로필 사진·프레임·칭호·카드 배경·이름 꾸미기·타일 테마의 목록이 나와요.
   - 이름, 가격을 고치고 "바뀐 내용 저장"을 누르면 바뀐 줄만 저장돼요. (노란 줄이 바뀐 줄)
   - **판매 중**을 끄면 상점에서만 사라져요. 이미 산 사람은 계속 써요. (보통은 이걸 쓰세요)
   - **완전 삭제**는 목록과 이미지 파일까지 지워요. 이미 산 사람도 못 써요. 기본 테마(12귀월·기본 숫자)와 업적·미션 칭호는 삭제할 수 없어요.
   - 가격을 비우면 무료예요 (프로필 사진·프레임·테마). 카드 배경·이름 꾸미기·칭호는 가격이 꼭 있어야 해요.
   - **칭호**: "새 칭호 만들기"에 이름·가격·묶음만 적으면 골드로 파는 칭호가 상점에 올라가요.
   - **타일 테마 가격**: 새 테마 / 덮어쓰기 화면의 가격 칸이나 여기서 정해요. 가격이 있으면 앱에서 골드로 사야 바꿀 수 있고, 지금 쓰고 있는 사람은 계속 써요.
5. **이벤트** (시트 없이 쓰는 탭) — 배팅 이벤트를 만들고 고쳐요.
   - 이름, 시작일·종료일, 이긴 편 보상(골드), 두 편의 이름과 색을 정해요. 시작일 오전 6시에 시작하고, 종료일 다음 날 오전 6시에 끝나요.
   - **대결 설명**: 이벤트 제목 바로 아래에 보이는 한 줄 문구예요 (80글자까지, 비워 두면 안 보여요).
   - **대결 그림**: 이벤트 화면 맨 위에 크게 나오는 그림이에요. 두 편이 맞붙는 모습을 가로로 긴 그림(예: 1000x560)으로 올려요. 각 편의 작은 그림(정사각형)은 선택이에요.
   - **골드 걸기** 체크: 참가할 때 min~max 골드를 걸어요 (이때 "이긴 편 보상"은 쓰지 않아요). 끝나면 이긴 편은 건 골드와 함께 진 편이 잃은 골드의 절반을 건 금액 비율로 나눠 받고, 진 편은 건 골드의 절반을 돌려받아요. 무승부이거나 한쪽에만 걸면 전부 돌려받아요. 참가하기 전까지는 편별 점수·인원이 비공개예요 (골드를 건 뒤에는 보여요). 이 기능을 쓰려면 Firestore 규칙의 ev 에 `g` 칸이 허용돼 있어야 해요.
   - 기간이 겹치는 이벤트는 만들 수 없어요. 이벤트는 앱의 `www/events/events.json` 과 그림 파일로 저장돼요.
   - push 하면 웹이 새로 배포되고, 앱은 인터넷이 연결돼 있으면 새 APK 없이도 새 이벤트를 보여줘요.
   - 이벤트를 지우면 그림도 지워져요. 이미 참가한 사람의 기록은 그대로 남아요.
6. **투표** (시트 없이 쓰는 탭) — 앱 "테마 투표"에 올릴 투표를 만들어요.
   - 투표 이름, 시작일·마감일, 후보 2~8개(이름 16글자·한 줄 설명·그림 선택)를 정해요. 아이디어 게시판의 댓글을 보고 괜찮은 아이디어를 후보로 올리세요.
   - 기간이 겹치는 투표는 만들 수 없어요. 투표는 `www/events/polls.json` 과 그림 파일로 저장돼요.
   - 이미 표가 있는 투표를 고칠 때는 후보를 지우거나 바꾸지 마세요. 후보 id 는 그대로 지켜지지만 지운 후보에 던진 표는 사라져요.
   - push 하면 웹이 새로 배포되고, 앱은 새 APK 없이도 새 투표를 보여줘요. 끝난 투표는 2주 동안 1위 결과가 보여요.
7. **공지** (시트 없이 쓰는 탭) — 앱 홈 맨 위에 계속 흘러가는 공지 배너를 관리해요.
   - 글(120글자), 시작일·마감일(비워도 됨), 켜기/끄기. 켜진 공지가 여러 개면 ◆ 로 이어져 한 줄로 흘러요. 보일 공지가 없으면 배너가 안 보여요.
   - `www/events/notices.json` 에 저장돼요. push 하면 새 APK 없이 바뀌어요.
7. 저장하면 화면에 나오는 `git add -A` / `git commit` / `git push` 를 PowerShell에 붙여 넣어요.

그림을 바꾸면 `shopdata.js` 의 `ver` 번호가 올라가서, 앱에 옛 그림이 남지 않아요.
덮어쓰기를 되돌리려면 git 의 이전 커밋으로 돌아가면 돼요.

7. **알림** (시트 없이 쓰는 탭) — 앱 홈에 카드로 뜨는 알림을 만들어요. (예: 새 타일 테마가 나왔을 때 "새 타일을 확인해 보세요" + 상점으로 가는 버튼)
   - 종류(새 타일 테마·이벤트·투표·업데이트·안내), 제목(24글자), 내용(100글자), 이동할 화면과 버튼 글자, 시작일·마감일, 켜기/끄기를 정해요. 최대 10개, 홈에는 한 번에 3개까지 보여요.
   - 사용자가 ✕ 나 버튼을 누르면 그 알림은 그 기기에서 다시 안 나와요. 닫은 사람에게도 다시 보이게 하려면 "다시 띄우기"(새 id)를 누르고 저장하세요.
   - 알림은 앱의 `www/events/alerts.json` 으로 저장돼요. push 하면 웹이 새로 배포되고, 앱은 새 APK 없이도 바뀌어요.
