# 상점 관리 프로그램

시트 이미지를 올리면 자동으로 잘라서 상점(`www/js/shopdata.js` + `www/images/`)에 올려 주는 프로그램이에요.
내 컴퓨터(localhost)에서만 열려요.

## 켜기
```
npm install        # 처음 한 번만
npm run admin      # 브라우저가 자동으로 열려요 (http://localhost:5050)
```
끄려면 터미널에서 `Ctrl+C`.

## 쓰는 법
1. **시트 이미지 고르기** — 4x4 정사각형 칸에 검은 격자선이 또렷한 이미지 (칸 번호는 왼쪽 위부터 가로로 1~16). 칸 16개가 미리보기로 나와요.
2. **타일 테마 시트**
   - *새 테마로 추가*: id(영문), 이름, 분류, 설명, 타일 이름을 적고 올려요. 14칸(2~8192 + 큰 이미지)이 필요해요.
   - *기존 테마 덮어쓰기*: 덮어쓸 테마를 고르면 지금 그림과 새 그림이 나란히 보여요. 바꿀 타일만 체크하세요. "새 시트 칸"으로 어느 칸의 그림을 쓸지도 고를 수 있어요.
3. **프로필 사진 시트** — 올릴 칸만 체크하고 id(영문)·이름·가격(0이면 무료)을 적어요. 이미 있는 id 를 쓰면 그 사진의 그림이 바뀌어요.
4. 저장하면 화면에 나오는 `git add -A` / `git commit` / `git push` 를 PowerShell에 붙여 넣어요.

그림을 바꾸면 `shopdata.js` 의 `ver` 번호가 올라가서, 앱에 옛 그림이 남지 않아요.
덮어쓰기를 되돌리려면 git 의 이전 커밋으로 돌아가면 돼요.
