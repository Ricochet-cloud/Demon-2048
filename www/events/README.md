# 배팅 이벤트 파일

`events.json` 에 이벤트를 적으면 앱 홈에 "이벤트" 버튼이 나와요 (보통은 관리 도구가 만들어 줘요).
push 하면 웹(GitHub Pages)에 올라가고, 앱은 그 파일을 먼저 읽어서 앱을 새로 깔지 않아도 새 이벤트가 보여요.

```json
{ "events": [ {
  "id": "bm1",                      // 영문 소문자·숫자·_- 20자까지 (이벤트마다 달라야 해요)
  "title": "배트맨 vs 슈퍼맨",
  "start": "2026-12-01",            // 이 날 오전 6시에 시작
  "end": "2026-12-07",              // 이 날까지 (다음 날 오전 6시에 끝나요)
  "reward": 300,                    // 이긴 편 사람이 받는 골드
  "image": "bm1.webp",              // 맨 위 그림 (없어도 돼요, events/ 폴더 안 파일)
  "sides": [
    { "id": "a", "name": "배트맨", "image": "bm1-a.webp", "color": "#3b6fd4" },
    { "id": "b", "name": "슈퍼맨", "image": "bm1-b.webp", "color": "#c0392b" }
  ]
} ] }
```

- 이벤트는 한 번에 하나씩, 기간이 겹치지 않게 해 주세요. 끝난 뒤 7일 동안 결과와 보상 받기가 보여요.
- 새 이벤트에 참가하면 이전 이벤트 기록이 덮여서, 이전 이벤트 보상은 새 이벤트 참가 전에 받아야 해요.
